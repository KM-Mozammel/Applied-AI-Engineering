# Coordinate Geometry:
"""
ধরো তোমার কাছে একটি সাদা কাগজ আছে। এখন তুমি কাগজে একটি বিন্দু (Point) দিলে •
এখন প্রশ্ন হলো, এই বিন্দুটি কোথায় আছে? শুধু বিন্দু আঁকলেই হবে না। তার একটা ঠিকানা (Address) দরকার। এই Address-ই Coordinate।
"""
# Coordinate Plane:
"""
একটি Coordinate Plane-এ দুটি দিক থাকে।
x-axis → বাম ↔ ডান
y-axis → নিচ ↕ উপরে

            y
            ↑
            │
            │
────────────┼────────────→ x
            │
            │

যেখানে দুইটি Axis মিলেছে, সেটিকে বলে Origin। Origin-এর Coordinate: (0, 0)
"""
# একটি Point:
"""
ধরো, (4, 2)| এর মানে x = 4, y = 2 অর্থাৎ ডানদিকে ৪, উপরে ২

            y
            ↑
            │        • (4,2)
            │
────────────┼────────────→ x
            │
            
আর যদি হয় (-3, 2), তাহলে বামদিকে ৩, উপরে ২
"""
# একটি Coordinate আসলে কী?
"""
একটি Coordinate-এর দুটি সংখ্যা থাকে। (x, y); Python-এ এটি লেখা যায়, point = (4, 2) অথবা point = [4, 2]
এখানে, Index 0 → x | Index 1 → y
অর্থাৎ,
"""
point = [4, 2]
print("X-Coordinate: ", point[0])  # x
print("Y-Coordinate: ", point[1])  # y
# Output: 4 2
