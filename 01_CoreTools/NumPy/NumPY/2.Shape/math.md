# Square Matrix মানে Rows = Columns

ধরুন আপনার কাছে ১,০০০ জন মানুষের তথ্য আছে। প্রত্যেকের ৫টি বৈশিষ্ট্য (Feature) আছে।

X.shape: (1000,5)

অর্থাৎ:
1000 Rows → 1000টি Sample
5 Columns → প্রতিটি Sample-এর 5টি Feature

Machine Learning-এ এটি একটি Feature Matrix নামে পরিচিত।
